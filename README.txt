GANG NARCO — VERSION 14

این نسخه شامل رتبه‌بندی سه بخش «بیشترین فعالیت»، «برترین راب‌ها» و «بیشترین امتیازات» با ترتیب اعلام‌شده است. دستاوردهای مرتبط نیز در تب «افتخارات» پروفایل شخصی اعضای حاضر در رتبه‌بندی نمایش داده می‌شود.

برای انتشار در GitHub Pages، فایل HTML را با نام index.html در ریشه مخزن قرار دهید. این رتبه‌بندی‌ها به‌صورت محتوای ثابت در سایت ثبت شده‌اند و هنوز به پنل مدیریت یا دیتابیس متصل نیستند.
